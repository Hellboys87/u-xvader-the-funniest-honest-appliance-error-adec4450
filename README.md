A tiny Node program that writes one brutally honest appliance error line to `entry.txt`: a washing machine stops hiding behind an unbalanced-load code, blames the fourteen towels and the single sock that caused it, and refuses to waddle across the floor again. The line is 137 characters, inside the competition's 200-character limit, and the program throws if the line is ever empty or over that limit.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
